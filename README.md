# Семейный бюджет

Простой веб-калькулятор семейного бюджета: доходы, расходы, анализ остатка и расчёт срока цели накоплений. Данные хранятся только в браузере (LocalStorage).

## Возможности

- Приветственная главная страница
- Учёт доходов и расходов по категориям
- Сводка: доход, расходы, остаток, доля сбережений
- Текстовый анализ состояния бюджета
- Цель накоплений и оценка срока
- Сохранение и очистка данных в LocalStorage
- Светлая и тёмная тема

## Как открыть

Откройте `index.html` в браузере или поднимите локальный сервер из корня проекта:

```bash
# Python
python -m http.server 8080

# Node.js (если установлен npx)
npx --yes serve .
```

Затем перейдите на `http://localhost:8080`.

## Технологии

HTML, CSS и JavaScript без фреймворков и сборки. Подходит для обучения и локального использования.
